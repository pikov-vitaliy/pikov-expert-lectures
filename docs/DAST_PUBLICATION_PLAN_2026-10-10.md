# Публикация материалов по динамическому анализу

Дата: 2026-10-10. Область публикации: `dast.pikov.expert` и корень `pikov.expert`.

## Концепция и исходное состояние

Сайт — сеть самостоятельных статических учебных разделов. Канонический реестр
находится в `_PROJECT/lectures.json`; двуязычные данные классического каталога
в `index.html` служат источником для `/ru/`, `/new/` и `/new/ru/`.
Новая версия главной остаётся альтернативной и сохраняет `noindex,follow`.

Авторский лендинг по первой редакции проекта стандарта становится главной
страницей DAST. Сохраняются все 18 разделов, словарь, интерактивная карта,
три схемы и цикл дефекта. Раздел не выдаёт проект стандарта за утверждённый
документ и не подразумевает перевод русских лекций на английский.

## План

1. Скопировать подготовленный лендинг и его графику без изменения оригиналов.
2. Добавить авторство, возврат в каталог, метаданные, прямой вход в практику
   и скачивание материалов. Сохранить оформление исходного лендинга.
3. Опубликовать методички AFL++, libFuzzer и разбор исправления в HTML/PDF/MD.
   Подготовить воспроизводимый публичный ZIP из выбранных исходников, seed-данных,
   образцов результатов и методичек. Исключить `.git`, конфигурацию редактора,
   служебные отчёты, подсказки агентам и готовые исполняемые файлы.
4. Добавить карточку DAST рядом с SAST в реестр, обе версии каталога на двух
   языках и учебную карту. Пересобрать генерируемые страницы и sitemap.
5. Проверить границы релиза, ссылки, документы, ZIP, адаптивность, интерактив,
   скачивание и переход из каждой главной. Выполнить стандартные local gates.
6. Зафиксировать изменения, провести PR/CI и собрать accepted release точного SHA.
   Опубликовать только два указанных домена. Проверить live bytes/MIME/headers
   и браузерные сценарии на опубликованных страницах.
7. Инвентаризировать старые `_deploy_pikov_*`, сохранить нужные резервные копии
   локально с хешами, после live-проверок удалить проверенные временные каталоги.

## Границы проверки

Команды лабораторных работ сохраняются из подготовленных методичек с их
зафиксированным окружением. Проверка публикации не означает повторное выполнение
всех команд фаззинга. Неизменённые нормативные документы представлены как источники
учебного разбора; новый аудит актуальности законодательства в задачу не входит.

## Проверяемый результат

- DAST открывается по HTTPS, вся локальная графика и практика доступны.
- Четыре входа каталога содержат согласованную карточку; языковые переходы работают.
- Публичный ZIP самодостаточен и не содержит истории Git или приватного инструментария.
- Сохранены evidence сборки, CI, deployment, browser QA и уборки.
- Итоговый отчёт предоставлен в Markdown, HTML и PDF.
