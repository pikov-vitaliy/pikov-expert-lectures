# EP01 — Where Secure Development Begins

**Проект первого выпуска для репетиции.** Серия *Secure Software Development in Practice*. Автор: Vitaliy Pikov. Подготовлено 6 сентября 2026 года.

Тема: введение в серию, история безопасной разработки, создание редакции ГОСТ 2016 года и процесс **5.1 «Планирование процессов разработки безопасного программного обеспечения»** ГОСТ Р 56939-2024. Материалы выступления — на английском. **25 слайдов, рабочая длительность 40 минут**; окончательная длительность определяется репетицией и монтажом, увеличение автором разрешено.

## Начать подготовку

1. Открыть [веб-презентацию](index.html). По умолчанию — последовательное чтение всех слайдов; режим Presentation — выступление с навигацией. Кнопка Speaker notes показывает полный текст речи. Управление: стрелки, Page Up / Page Down, Home / End; Escape возвращает к чтению.
2. Прочитать [план и режиссуру](EP01-plan.md), затем [полный английский сценарий по слайдам](EP01-script-en.md).
3. Сделать пробную запись по [памятке для репетиции](EP01-rehearsal.md) и сверить её с [расчётом хронометража](EP01-timing.md).
4. Для глубокого изучения исходного вебинара прочитать [полную тематическую лекцию на русском](PVS-2025-07-02-lecture.html) или её [Markdown-версию](PVS-2025-07-02-lecture.md). Все документы и английская речь собраны также в [HTML-обзоре комплекта](review.html).

## Как редактировать

Изменять содержание и речь в `EP01-script-en.md`, сохраняя поля `Seconds`, `Section`, `Layout`, `Lead`, `Items`, `Sources`, `Speech`, `Cue`. Плановая общая длительность задаётся строкой `Target: mm:ss`; число слайдов определяется автоматически, номера идут подряд от 1. Для контакта на последнем слайде используется поле `Contact: имя | видимый адрес | HTTPS URL`. Затем выполнить `python build-content.py` из этой папки. Скрипт обновит `assets/episode-data.js` и `EP01-timing.md`, проверяя сумму времени. Источники для отображения задаются в `build-content.py`; подробная методическая запись — в `EP01-sources.md`.

Для двух HTML-материалов выполнить `py -3.14 build-review.py` (нужны библиотеки `markdown` и `beautifulsoup4`, доступные в этой среде). Генератор находится в репозитории, читает актуальные Markdown и данные слайдов, не зависит от временных HTML предыдущих задач. `--check` проверяет сборку без записи. После браузерной проверки `--archive "V:\tmp\codex\YYYY-MM-DD\YYYY-MM-DD-тема.html" --qa-text "Результат проверки"` создаёт новую архивную копию; существующий архив не перезаписывается. После изменений перезагрузить страницу.

Презентация использует обычные HTML, CSS и JavaScript, локальные файлы и системные шрифты. Сервер, сборщик и интернет для чтения не требуются. Для проверки через локальный сервер: `python -m http.server 8765 --bind 127.0.0.1 --directory .`; открыть `http://127.0.0.1:8765/`. Это локальный просмотр, а не публикация сайта. Политика конкретного встроенного браузера может ограничивать открытие локальных файлов.
