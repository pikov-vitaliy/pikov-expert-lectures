# EP01 — Where Secure Development Begins

**Проект первого выпуска для репетиции.** Серия *Secure Software Development in Practice*. Автор: Vitaliy Pikov. Подготовлено 6 сентября 2026 года.

Тема: введение в серию, история безопасной разработки, российский контекст и процесс **5.1 «Планирование процессов разработки безопасного программного обеспечения»** ГОСТ Р 56939-2024. Материалы выступления — на английском. Рабочая длительность — 30 минут; окончательная длительность определяется репетицией и монтажом.

## Начать подготовку

1. Открыть [веб-презентацию](index.html). По умолчанию — последовательное чтение всех слайдов; режим Presentation — выступление с навигацией. Кнопка Speaker notes показывает полный текст речи. Управление: стрелки, Page Up / Page Down, Home / End; Escape возвращает к чтению.
2. Прочитать [план и режиссуру](EP01-plan.md), затем [полный английский сценарий по слайдам](EP01-script-en.md).
3. Сделать пробную запись по [памятке для репетиции](EP01-rehearsal.md) и сверить её с [расчётом хронометража](EP01-timing.md).

## Как редактировать

Изменять содержание и речь в `EP01-script-en.md`, сохраняя поля `Seconds`, `Section`, `Layout`, `Lead`, `Items`, `Sources`, `Speech`, `Cue`. Затем выполнить `python build-content.py` из этой папки. Скрипт обновит `assets/episode-data.js` и `EP01-timing.md`. Источники для отображения задаются в `build-content.py`; подробная методическая запись — в `EP01-sources.md`. После изменения перезагрузить страницу.

Презентация использует обычные HTML, CSS и JavaScript, локальные файлы и системные шрифты. Сервер, сборщик и интернет для чтения не требуются. Для проверки через локальный сервер: `python -m http.server 8765 --bind 127.0.0.1 --directory .`; открыть `http://127.0.0.1:8765/`. Это локальный просмотр, а не публикация сайта. Политика конкретного встроенного браузера может ограничивать открытие локальных файлов.

Исторический блок обновлён по двум указанным пользователем PDF из подпапки «РАЗДАВАТЬ»: обзор методологий (27 страниц) и доклад об истории ГОСТ (26 страниц). Переписаны слайды 5–9 и их полная речь; 20 слайдов и целевые 30 минут сохранены.

Файлы PowerPoint и PDF не создавались по выбору автора. Видео, внешняя рецензия и финальная репетиция ещё не выполнены. Пример вымышленный; английские переводы положений — рабочие авторские. Этот выпуск не заявляет полного соответствия ГОСТ и не решает вопрос уникальности всех 25 процессов.
