# EP01 — Подготовка английской речи и записи

## Порядок репетиции

1. Прочитать слайды 1–4 вслух, записать звук и оценить темп по времени, а не ощущению. Затем отдельно проговорить исторические названия и номера пунктов.
2. Провести полный проход с [текстом](EP01-script-en.md). Таймер включить с первого слова; записать реальные границы блоков, паузы и места потери дыхания.
3. Сверить результат с [моделью хронометража](EP01-timing.md). После сверки речи с графикой — 4327 слов, 25 слайдов и 42:20 плановых слотов. Распределение времени и пауз обосновано в [проверке речи](EP01-speech-review.md). Ориентир артикуляции 120–125 слов/мин с паузами, а не обязательная скорость. При естественном темпе 110 слов/мин увеличивать длительность или сокращать повторы; автор разрешил расширение выпуска.
4. Повторно записать только трудные места: GOST designation, годы, shall/should, два плана и сравнительный вывод. Сохранять одинаковые английские термины.
5. Записать чистовые блоки по 3–5 слайдов. Начало и конец каждого блока оставить с короткой тишиной для монтажа. После склейки прослушать переходы целиком.

В режиме веб-показа отключить полный текст речи в захватываемой области экрана. Читать Markdown или speaker notes на отдельном экране/окне, которое не попадает в запись. Одно окно презентации с раскрытыми notes удобно для репетиции; отдельного синхронизированного телесуфлёра в проекте нет.

Отдельно отрепетировать слайды 5–13: фамилии Arina Kudriavtseva / Olga Gadyatskaya / Vitaliy Varenitsa; различие research project / working draft / approval / entry into force; числа twenty-two organizations / around two hundred comments; даты June 2016 / June 2017; хронологию SSDF 2019 / 2020 / 2022. После первого упоминания авторов можно говорить `the review` и `the retrospective`. Вареница — участник разработки и автор исторического рассказа, Пиков — автор текущего выпуска. В слайде 12 произнести различие nine groups of measures / twenty-five processes и объяснить, почему «следует» имеет разную силу в двух редакциях.

Перед репетицией прочитать [полную тематическую лекцию по исходному вебинару](PVS-2025-07-02-lecture.md). История и практическая часть разделены по содержательным докладам; техническая карта источника хранится в исследовательских материалах. Английская речь уже адаптирована к нашему выпуску; не добавлять поверх неё все двухчасовые обсуждения. Финальный слайд теперь 25: произнести `pikov dot expert`, полное название EP02 и оставить зрителю время прочитать адрес.

## Произношение и терминология

Подсказки ударения — приблизительные, не фонетическая транскрипция. Приоритет — понятная речь и единообразие.

| Term | Ударение / как произнести | Смысл |
|---|---|---|
| secure software development | se-CURE SOFTWARE de-VE-lop-ment | Разработка безопасного ПО |
| vulnerability | vul-ner-a-BI-li-ty | Подтверждённая уязвимость, не любое предупреждение |
| evidence | E-vi-dence | Неисчисляемое: evidence, some evidence; не evidences |
| scope | Односложное слово | Область применения, определённые границы |
| rationale | ra-tio-NALE | Обоснование выбора |
| requirements | re-QUIRE-ments | Требования |
| implementation | im-ple-men-TA-tion | Реализация |
| responsibility | re-spon-si-BI-li-ty | Ответственность за работу |
| traceability | trace-a-BI-li-ty | Прослеживаемость |
| maturity | ma-TU-ri-ty | Зрелость |
| triage | TREE-ahzh | Первичный разбор/приоритизация находок |
| NIST SSDF | NIST; S S D F | Сначала полное название, потом сокращение |
| OWASP SAMM | OH-wasp; sam | Software Assurance Maturity Model |
| SDL / CI | S D L / C I | Не смешивать CI и continuous deployment |
| PO.2.1 | P O, two point one | Идентификатор задачи в SSDF 1.1 |
| GOST R 56939-2024 | GOST R, five six nine three nine, twenty twenty-four | После первого полного упоминания достаточно the standard |

Рабочие переводы: `process improvement plan` для «плана развития процессов» и `process implementation plan` для «плана реализации». В материалах обозначено, что переводы авторские. `Process procedure` обычно яснее, чем `regulation`, когда речь о внутреннем регламенте.

## Фразы, которые помогают держать нить

- “Let us make this concrete.”
- “The shared concern is …”
- “The difference is in the scope and expected evidence.”
- “This is an illustrative choice, not a prescribed timetable.”
- “Keep this example in mind; we will return to it.”
- “The comparison is partial.”

Это запасные связки для живой подачи; не добавлять все поверх полного сценария, иначе вырастет хронометраж.

## Контроль перед чистовой записью

- Автор прочитал весь текст и согласен с личным представлением и упоминанием прежнего проекта PVS-Studio.
- Даты и статусы источников перепроверены на дату записи; SSDF 1.2 не назван final без нового подтверждения.
- Термины «следует», «должен», CI/CD и разница двух планов произносятся без изменения смысла.
- Речь укладывается в выбранный темп; места пауз отмечены после пробной записи.
- Обложка и слайды читаются в реальном размере окна записи; лицо не перекрыто интерфейсом.
- В записи нет редакторских подсказок, уведомлений, личных данных других приложений или незаполненных ссылок публикации.
- После монтажа субтитры вручную сверены для имён, сокращений и номеров стандартов.

Это производственная памятка. Выполнение пунктов не считается установленным до реальной записи автора.
