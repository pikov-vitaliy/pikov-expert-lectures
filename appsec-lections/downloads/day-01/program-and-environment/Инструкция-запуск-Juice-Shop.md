# Запуск OWASP Juice Shop

## Старт

```bash
docker run --rm -p 3000:3000 -e NODE_ENV=unsafe bkimminich/juice-shop
```

Открыть в браузере: **http://localhost:3000**

## Флаги

| Флаг | Значение |
|------|----------|
| `docker run` | Создать и запустить контейнер |
| `--rm` | Автоматически удалить контейнер после остановки (не захламляет диск) |
| `-p 3000:3000` | Пробросить порт: левая `3000` — на твоём компьютере, правая — внутри контейнера |
| `-e NODE_ENV=unsafe` | Включить режим с уязвимостями (без него часть заданий не сработает) |
| `bkimminich/juice-shop` | Название образа |

## Остановка

Нажать `Ctrl+C` в окне терминала. Контейнер удалится сам благодаря `--rm`.

## Сброс прогресса

Остановить `Ctrl+C` и запустить заново той же командой — состояние будет чистым.

## Если порт 3000 занят

```bash
docker run --rm -p 3001:3000 -e NODE_ENV=unsafe bkimminich/juice-shop
```

Тогда открывать: **http://localhost:3001**
