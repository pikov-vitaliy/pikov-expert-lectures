**Инструкция по запуску OWASP Juice Shop**

В этой инструкции предполагается, что на компьютере **не установлено ничего** (нет Docker, нет дополнительных инструментов). После выполнения инструкции приложение будет доступно по адресу [**http://localhost:3000**](http://localhost:3000/).

Если у вас уже установлен Docker, вы можете пропустить Шаг 1.

**Шаг 1. Установить Docker**

**Windows**

1. Откройте сайт:
   <https://www.docker.com/products/docker-desktop/>
2. Скачайте **Docker Desktop for Windows**.
3. Запустите установщик.
4. Во время установки:
   * оставьте настройки по умолчанию;
   * если появится предложение установить **WSL 2**, согласитесь.
5. После установки **перезагрузите компьютер**, если система попросит.
6. Запустите **Docker Desktop**.
7. Дождитесь появления сообщения:

   Docker Desktop is running

   или зелёного индикатора в окне программы.

**Linux (Ubuntu)**

Откройте терминал и выполните:

sudo apt update

sudo apt install docker.io -y

Запустите Docker:

sudo systemctl enable docker

sudo systemctl start docker

Проверьте работу:

docker --version

Например:

Docker version 28.x.x

**macOS**

1. Скачайте Docker Desktop с официального сайта.
2. Установите приложение.
3. Запустите Docker Desktop.
4. Дождитесь запуска службы Docker.

**Шаг 2. Проверить работу Docker**

Откройте терминал.

**Windows**

Нажмите:

Win + R

Введите:

cmd

или откройте **PowerShell**.

Введите команду:

docker --version

Если всё установлено правильно, появится что-то вроде:

Docker version 28.0.1, build ...

**Шаг 3. Запустить Juice Shop**

В терминале выполните команду *(в Linux добавьте перед командой ниже sudo)*:

docker run --rm -p 3000:3000 -e NODE\_ENV=unsafe bkimminich/juice-shop

При первом запуске Docker автоматически скачает образ (около нескольких сотен мегабайт).

В терминале будут отображаться сообщения вида:

Unable to find image...

Pulling...

Downloading...

Это нормально.

После завершения загрузки появятся сообщения о запуске сервера.

**Не закрывайте окно терминала**, пока работает приложение.

**Шаг 4. Открыть приложение**

Откройте браузер и перейдите по адресу:

http://localhost:3000

Если всё выполнено правильно, откроется главная страница **OWASP Juice Shop**.

**Шаг 5. Остановить приложение**

Чтобы остановить сервер:

1. Вернитесь в окно терминала.
2. Нажмите:

   Ctrl + C

Контейнер будет остановлен и автоматически удалён (из-за параметра --rm).

**Возможные проблемы**

**Команда docker не найдена**

Сообщение:

'docker' is not recognized...

или

docker: command not found

**Решение:**

* убедитесь, что Docker Desktop установлен;
* перезапустите терминал;
* если проблема сохраняется — перезагрузите компьютер.

**Docker Desktop не запускается**

На Windows чаще всего причина — отключена виртуализация.

Проверьте:

* включена ли виртуализация (Intel VT-x или AMD-V) в BIOS/UEFI;
* установлен ли WSL 2 (для Windows 10/11).

**Порт 3000 уже используется**

Если появляется сообщение:

Bind for 0.0.0.0:3000 failed

значит порт занят другим приложением.

Можно использовать другой порт, например:

docker run --rm -p 3001:3000 -e NODE\_ENV=unsafe bkimminich/juice-shop

Тогда приложение будет доступно по адресу:

http://localhost:3001

**Проверка запуска**

Запуск считается успешным, если:

* Docker успешно установлен и запущен;
* команда запуска контейнера выполнена без ошибок;
* в браузере открывается страница **OWASP Juice Shop** по адресу [**http://localhost:3000**](http://localhost:3000/) (или по другому выбранному локальному порту, если 3000 занят).
