## 2. Какие знания нужны студенту до выполнения

|  |  |
| --- | --- |
| |  | | --- | | **💡 Подсказка** Перечислите знания и навыки, которыми студент должен владеть до начала работы. Если вам самим не хватило каких‑то знаний во время выполнения лабораторной — добавьте их в список. | |

**Пример**

* Основы TCP/IP
* Основы HTTP
* Базовые команды Linux
* Docker
* Базовые знания SQL

## 3. Что нужно получить от студента в результате

|  |
| --- |
| **💡 Подсказка** Определите 2–3 артефакта, по которым можно быстро проверить успешное выполнение лабораторной работы. Не оценивайте каждый шаг — оценивайте конечный результат. |

**Пример**

* Скриншот с решённой задачей (таблицу результатов) или иной явный индикатор успеха.
* Ключевой артефакт: ссылку URL, состояние страницы, фрагмент запроса/ответа, конфигурацию или содержимое файла.

## 4. Гипотетические типовые ошибки студентов

|  |
| --- |
| **💡 Подсказка**  Во время выполнения представляйте, что лабораторную проходит ваш студент.  На каких этапах он, скорее всего, попросит помощи? Именно эти места стоит доработать. |

**Пример**

* Неправильно настроено окружение
* Пропущен обязательный шаг
* Неверно интерпретирован результат
* Использованы неверные параметры

## 5. Как оценивать работу

|  |
| --- |
| **💡 Подсказка**  Сначала определите критерии оценки, затем распределите их по значимости. Наибольший вес должны иметь критерии, связанные с достижением основной цели лабораторной.  В сумме критерии должны составлять 100%. |

|  |
| --- |
| **Пример** |

|  |  |
| --- | --- |
| **Критерий** | **Вес** |
| Получен ожидаемый результат | 30% |
| Выполнены обязательные шаги | 30% |
| Студент объяснил выполненные действия | 20% |
| Предложены меры по устранению | 15% |
| Оформление отчёта | 5% |

## 6. Как избежать риска / исправить ошибки в реальном приложении

|  |
| --- |
| **💡 Подсказка**  Лабораторная моделирует реальную профессиональную задачу. Подумайте, как подобную проблему предотвращают в промышленной разработке, а не только как её исправить. |

|  |
| --- |
|  |

**Пример**

* Валидация пользовательского ввода
* SAST/DAST
* Принцип минимальных привилегий
