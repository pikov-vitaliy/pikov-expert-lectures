# Офлайн-комплект: Сканер-ВС 7 и «Инспектор»

Полностью распакуйте архив в отдельную папку и откройте `index.html`. Все ссылки на лабораторные материалы внутри комплекта относительные и работают без подключения к Интернету.

Дистрибутив Сканер-ВС, файл лицензии, загрузочные образы и виртуальные машины в архив не входят. Актуальную демоверсию Сканер-ВС 7 Base и файл лицензии каждый слушатель получает самостоятельно через [официальную форму производителя](https://scaner-vs.ru/#form).
