Единый маршрут по Сканер-ВС и «Инспектору»

Полный набор для преподавателя и слушателя: общая инструкция, четыре варианта практики по Сканер-ВС, отдельный практикум по компоненту «Инспектор» и шаблоны доказательных отчетов.

Перед началом

Сначала полностью распакуйте архив в отдельную папку и откройте общую инструкцию комплекта. При работе из окна архиватора относительные ссылки могут быть недоступны.

Что не входит в комплект

Дистрибутив Сканер-ВС и файл лицензии не включены. Свежую демоверсию получают через официальную форму разработчика.

Быстрый маршрут

Как работать с комплектом

  1. Откройте README. Проверьте состав архива и общие ограничения.
  2. Выберите практику по Сканер-ВС. Начните с общего процесса, затем выберите ScanOVAL, WSL, VirtualBox или Live USB.
  3. Пройдите практикум «Инспектор». Работайте только в подготовленной учебной среде.
  4. Оформите результаты. Для каждого продукта используйте его шаблон отчета.

Единое правило безопасности

Все проверки выполняются только на собственных или явно разрешенных объектах. Уязвимые виртуальные машины изолируются от внешних сетей, а реальные учетные данные и производственная информация в практикуме не используются.

Полный офлайн-комплект работает после распаковки архива. Перед каждым занятием преподаватель проверяет версии продуктов, доступность дистрибутива и совместимость лабораторного стенда.
