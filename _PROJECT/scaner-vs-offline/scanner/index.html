Перед началом

Сначала полностью распакуйте архив в отдельную папку и только затем открывайте этот файл. Иначе ссылки на материалы, стили и изображение могут не работать.

Что не входит в комплект

Дистрибутив Сканер-ВС и файл лицензии в архив не включены. Актуальную демоверсию получают у разработчика через официальную форму Сканер-ВС.

Копируемая шпаргалка

Установка Сканер-ВС 7 в WSL

Команды перенесены из предоставленной учебной инструкции, страницы 3-5. Полное объяснение, безопасная настройка сети и откат находятся в пошаговой Markdown-инструкции.

1 · PowerShell от администратора

Подготовить WSL

wsl --install
wsl --install Ubuntu
wsl -d Ubuntu
wsl --list --verbose

Если имя установленного дистрибутива отличается, используйте имя из списка. После включения WSL может потребоваться перезагрузка.

2 · Ubuntu

Установить продукт

sh scanner-signed-deb.run
cp license.lic pkg/
cd pkg/
./installer install

Подставьте фактическое имя свежего .run-файла. Лицензия должна находиться в pkg до запуска installer.

3 · Только при сетевом доступе

Перенаправить HTTPS

netsh interface portproxy add v4tov4 listenport=443 listenaddress=<IP_Хоста> connectport=443 connectaddress=<IP_WSL>
New-NetFirewallRule -DisplayName "Allow Scanner UI" -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow

Замените оба заполнителя реальными адресами. Для занятия ограничьте удалённые адреса разрешённой лабораторной подсетью; не отключайте брандмауэры целиком.

4 · Проверка

Подтвердить результат

systemctl status scanner
netsh interface portproxy show all

Откройте https://localhost, смените первоначальный пароль и после занятия удалите только созданные временные правила. Не используйте общий portproxy reset.

Схема практики

От подготовки стенда до проверяемого отчета

Используйте схему как навигацию по занятию: сначала определите разрешенные границы, затем исследуйте и инвентаризируйте активы, выполните проверки и разберите результат.

Безопасная практика

Сканируйте только собственные или явно разрешенные узлы. Виртуальный уязвимый стенд изолируйте от рабочей и домашней сети, а для учебных подключений используйте отдельные учетные записи без реальных паролей.

Материалы работают локально после полной распаковки архива. Для актуальности требований и функций сверяйтесь с документацией производителя перед каждым занятием.
