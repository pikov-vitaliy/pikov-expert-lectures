# Самостоятельная работа по модулю 4 и контрольная точка

**Объём:** 2 академических часа: 1 ак. ч по теме 4.1 и 1 ак. ч по теме 4.2 с контрольной точкой модуля 4.
**Срок:** до начала следующего занятия, 25.11.2026, 08:00.
**Куда сдавать:** обе части внести в раздел 4 рабочей тетради и загрузить тетрадь целиком на Платформу в задание «Контрольная точка по модулю 4».
**Материалы:** файл «Учебный кейс ЭС-24: дополнение к четвёртому дню», разделы 4 и 7. ТЗ – редакция 1 из кейса первого дня, если в задании прямо не сказано иное.

## Часть 1. Тема 4.1: расчёт с ИИ и независимый пересчёт (45 мин)

Задача 2 из раздела 4 дополнения к кейсу: расход заряда батарей на стоянке.

1. **Постановка (10 мин).** Составьте запрос к модели по образцу задания 1 практики 4.1: исходные данные с единицами, допущения из условия, требование показать каждую подстановку с единицами, просьба перевести миллиамперы в амперы и сутки в часы отдельной строкой.
2. **Расчёт моделью (10 мин).** Отправьте запрос в сервис, разрешённый правилами вашей организации. Сохраните ответ целиком.
3. **Независимый пересчёт (20 мин).** Пересчитайте все пять величин сами: на калькуляторе, в табличном редакторе или вручную. Не той же моделью и не в том же чате: повторный вопрос модели независимым пересчётом не считается.
4. **Вывод (5 мин).** Ответьте на вопрос 6 задачи: что можно и чего нельзя утверждать по этим расчётам о выполнении п. 4.4 и 4.5 ТЗ.

Форма результата части 1 (раздел 4.1 тетради):

|---|---|---|---|

| 4. Суток до 50 % при 62 мА | | | |

## Часть 2. Тема 4.2 и контрольная точка модуля 4: выводы по таблице испытаний (45 мин)

Таблица 2 из раздела 7 дополнения к кейсу: напряжение регулятора восьми генераторов при −25, 0, +25 и +50 °C.

1. **Анализ моделью (15 мин).** Отправьте модели таблицу текстом и запрос по образцу задания 1 практики 4.2. Не забудьте указать, что требование п. 4.2 ТЗ редакции 1 (28,2 ± 0,3 В) задано только для +25 °C. Попросите оценить соответствие, посчитать среднее, наименьшее и наибольшее значение при каждой температуре, найти подозрительные значения и описать тенденцию.
2. **Выборочная проверка (20 мин).** Проверьте ответ по шести шагам из лекции 4.2. Пересчитайте не меньше пяти чисел из ответа по исходной таблице. Отдельно проверьте, что модель сделала с двумя особыми ячейками таблицы: значением 2,846 В у Г-03 и отсутствующим замером у Г-08.
3. **Выводы (10 мин).** Напишите выводы по таблице 2 в виде раздела отчёта: применимые требования, несоответствия поимённо, вопросы к данным, тенденция, оговорка об объёме выборки, строка «Как проверено».

Форма результата части 2 (раздел 4.2 тетради):

| Раздел | Содержание |
|---|---|
| Запрос | Полный текст запроса |
| Сервис | Какой сервис и режим использовали |
| Ответ модели | Целиком или основная часть |
| Выборочная проверка | Таблица: число из ответа – мой пересчёт – совпало ли; не меньше пяти строк |
| Ошибки модели | Что нашли: пропуски, выдуманные значения, неверные статистики, не тот допуск, тихие правки |
| Выводы | Раздел отчёта, исправленный вручную |

## Какие материалы использовать

В рамках задания отправляйте в сервис только учебные таблицы и условия задач из кейса. Если хотите попробовать приёмы на своих расчётах и протоколах, делайте это только в сервисе, который разрешён для таких данных правилами вашей организации, и не прикладывайте рабочие данные к домашнему заданию.

## Как будет оцениваться

Контрольная точка засчитывается (зачёт по разделу 4 тетради), если:

- в части 1 есть независимый пересчёт всех пяти величин и вывод по вопросу 6 не шире расчёта;
- в части 2 проверено не меньше пяти чисел ответа модели по исходной таблице;
- несоответствия по таблице 2 оценены только по тем условиям, для которых в ТЗ (редакция 1) есть требование;
- подозрительное значение и пропущенный замер названы как вопросы к данным, а не исправлены и не заполнены;
- в материалах нет служебных сведений.
