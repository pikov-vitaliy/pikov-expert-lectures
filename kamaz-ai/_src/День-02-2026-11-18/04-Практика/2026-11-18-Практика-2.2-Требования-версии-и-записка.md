# Практика к теме 2.2. Требования, редакции, снимки и служебная записка

**Время:** 4 академических часа (13:00–14:30 и 14:40–16:10).
**Что понадобится:** учебный кейс ЭС-24 первого дня (раздел 2 – редакция 1 технического задания), файл «Учебный кейс ЭС-24: дополнение ко второму дню» (документы 4, 5, 7), один-два сервиса, телефон или программа для снимков экрана.
**Правило:** только учебные документы.
**Какая редакция дальше:** редакция 2 нужна для заданий этого дня – её выпуск и сравнение с редакцией 1. В днях 3–5 задания выполняются по редакции 1 ТЗ (день 1), если в задании прямо не сказано иное.

## Задание 1. Требования редакции 2 в таблицу (40 мин)

### 1а. Извлечь (15 мин)

Откройте новый чат. Отправьте документ 5 (редакция 2 раздела 4 ТЗ) с запросом:

```
Ниже раздел 4 технического задания, редакция 2. Составь таблицу
со столбцами: пункт – требование – параметр – значение – условия.
Для каждой строки приведи дословную фразу из пункта в кавычках.
Бери только то, что написано в тексте. Если условие не указано,
пиши «не указано». Если в пункте несколько требований, сделай
отдельную строку для каждого.

[вставьте документ 5]
```

### 1б. Сверить (15 мин)

Сверьте таблицу с документом построчно:

1. Сколько пунктов в документе и сколько строк в таблице? Не пропущен ли пункт или второе требование внутри пункта (например, смазка в 4.7)?
2. Найдите каждую дословную фразу в документе поиском (Ctrl+F). Все ли нашлись?
3. Совпадают ли числа, допуски и единицы?
4. Не появились ли условия, которых нет в тексте?

| Строка | Что не так | Как нашли |
|---|---|---|
| | | |

```
Через сколько минут после выключения зажигания измеряется ток покоя

```
Какой момент затяжки болтов генератора установлен в ТЗ?

## Задание 2. Сравнение редакций (45 мин)

### 2а. Перечень изменений от модели (15 мин)

Откройте новый чат и отправьте:

```
Ниже две редакции раздела 4 технического задания. Сравни их по пунктам.
Таблица: пункт – статус (без изменений / изменён / новый / удалён) –
что было (дословно) – что стало (дословно) – суть изменения.
Изменением считай только изменение числа, условия или обязанности.
Если изменилась только формулировка без смены смысла, так и напиши.

Редакция 1:
[вставьте раздел 2 учебного кейса первого дня]

Редакция 2:
[вставьте документ 5]
```

### 2б. Проверить по первоисточнику (20 мин)

Сравните сами, пункт за пунктом. Если в вашем текстовом редакторе есть функция сравнения документов, сначала сопоставьте редакции с её помощью: она покажет все различия в тексте, хотя и не объяснит их смысл.

Проверьте:

- не пропустила ли модель изменения, особенно когда в одном пункте их два;
- не назвала ли изменением перефразировку без смены смысла;
- не нашла ли изменение в пункте, который не менялся;
- правильно ли модель отметила новые пункты.

|---|---|---|---|

| Единицы (мин⁻¹, Н·м, мА) | |

| Лишние слова | |

Если сервис не принимает изображения, работайте вдвоём с соседом, у которого принимает, или смотрите демонстрацию на экране преподавателя.

## Задание 4. Служебная записка по итогам сравнения (45 мин)

### 4а. Черновик (15 мин)

В чате, где вы делали задание 2, попросите:

```
Подготовь черновик служебной записки руководителю службы
о выпуске редакции 2 раздела 4 ТЗ ЭС-24. Включи:
1) что изменилось (по пунктам, со значениями «было – стало»);
2) какие замечания З-1…З-5 нужно переоценить и какие измерения повторить;
3) что требует решения руководителя.
Объём – не больше одной страницы. Не добавляй причин изменений
и выводов, которых нет в документах. Официально-деловой стиль без лишних слов.
```

### 4б. Проверить и исправить (20 мин)

- Каждое утверждение записки подтвердите пунктом документа. Неподтверждённое вычеркните.
- Сверьте значения «было – стало» с вашей таблицей из задания 2б.
- Вычеркните общие слова, которые ничего не сообщают.
- Проверьте, не придумала ли модель адресата, дату, номер или подпись.

### 4в. Обмен (10 мин)

Обменяйтесь записками с соседом. Найдите в его записке одну неточность или лишнюю фразу.

**Результат:** записка на одну страницу, которую можно было бы отправить после вашей правки.

## Дополнительно, для тех, кто уже работает с ИИ

1. **Смешанный чат.** В одном чате отправьте сначала редакцию 1, потом редакцию 2 без подписей и спросите: «Какой ток покоя допустим?». Ответила ли модель по последней редакции? Повторите с подписями «Редакция 1 (недействующая)» и «Редакция 2 (действующая)».
