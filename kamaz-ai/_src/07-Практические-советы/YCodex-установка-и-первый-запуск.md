# YCodex: установка и первый запуск

Инструкция. Документация сверена в ноябре 2026 года, тогда установщик выбирал версию 1.1.1. Флаги и ключи настройки – по справке этой сборки. Для Windows – установка Linux-версии в Ubuntu через WSL 2.

## 1. Что это

YCodex – консольный помощник Яндекса: читает файлы проекта, предлагает и вносит правки, запускает команды [1]. Это «опенсорс-инструмент Codex TUI, интегрированный с AI Studio» [5]. Модели по подписке: Alice AI Flash, DeepSeek v4.1 Flash, Qwen 3.6 35b [4]; по умолчанию DeepSeek [1].

## 2. Что понадобится

- Аккаунт Yandex Cloud с платёжным аккаунтом в статусе ACTIVE или TRIAL_ACTIVE [6].
- Подписка «Алиса AI Про» на вашего пользователя.
- Идентификатор облака и идентификатор каталога из этого облака.
- Linux, macOS или Windows с Ubuntu в WSL 2.

| Тариф | В месяц за сотрудника, с НДС | Для чего |
|---|---|---|
| Go | 2 490 ₽ | для знакомства с ИИ |
| Go X5 | 5 490 ₽ | для регулярной работы |
| Go X15 | 11 490 ₽ | для интенсивной работы |

Цены на ноябрь 2026 года [7]; подписка списывается каждый месяц независимо от использования.

## 3. Где чаще всего застревают

**Регистрация и подписка.** Консоль Yandex Cloud, платёжный аккаунт; затем aistudio.yandex.ru/manage, раздел «Подписки». Подписка на вас уже есть – второй раз не оформляйте. Платит предприятие – подписку назначает его администратор. Платите сами – «Оформить подписку», тариф, «К выбору сотрудников», себя, «К подтверждению», «Подтвердить и оформить» [6]. Покупать может роль admin на облако; для работы нужны роли resource-manager.clouds.member и resource-manager.viewer [5].

**Идентификатор облака.** Код облака – на странице облака, под названием, или в «Информация об облаке» [10]. Код каталога – под названием каталога или в «Информация о каталоге»; он же стоит в адресной строке console.yandex.cloud/folders/… [11]. Это разные коды, оба – от облака с подпиской.

## 4. Установка

Выберите свою систему, затем переходите к подготовке.

### Если у вас Windows

#### 1. Проверьте, есть ли Ubuntu

Откройте PowerShell (меню «Пуск», набрать powershell) и выполните:

PowerShell:

```
wsl -l -v
```

Есть Ubuntu (или Ubuntu-24.04) и в столбце VERSION стоит 2 – переходите к шагу 3. Стоит 1 – переведите: `wsl --set-version Ubuntu 2`, имя берите из столбца NAME. Ubuntu в списке нет – шаг 2.

#### 2. Установите Ubuntu в WSL 2

Нужны Windows 11 или Windows 10 версии 2004 и новее (сборка 19041). PowerShell – **от имени администратора** [13]:

PowerShell от администратора:

```
wsl --install -d Ubuntu
```

Перезагрузите компьютер. Ubuntu попросит придумать имя и пароль: это отдельная учётная запись, не учётная запись Windows. Когда вводите пароль, на экране ничего не появляется, так и должно быть [14].

Загрузка стоит на 0 % – выполните `wsl --install --web-download -d Ubuntu` [13].

> Рабочий компьютер: WSL ставится только с разрешения ИТ и безопасности. Нет разрешения – пробуйте на личном или учебном компьютере.

#### 3. Откройте Ubuntu

Меню «Пуск», Ubuntu. Или из PowerShell; имя – точно как в столбце NAME, например Ubuntu-24.04:

PowerShell:

```
wsl -d Ubuntu
```

> Дальше все команды – в окне Ubuntu, одинаково для Windows и Linux.

### Если у вас Linux или macOS

#### 1. Откройте терминал и проверьте компьютер

WSL не нужен. По руководству подходят macOS и Linux, архитектура x86_64 либо arm64 [1]:

Терминал:

```
uname -m
```

Подходят ответы `x86_64`, `aarch64` и `arm64`. В Debian и Ubuntu пакеты ставит `apt`, как в шаге «Подготовка». В других дистрибутивах ставьте `curl`, `python3` и `ca-certificates` своим менеджером; на Astra Linux и РЕД ОС установка не проверялась.

### Дальше одинаково для всех

#### 1. Подготовка

Установщику нужны Python 3.8 или новее и curl [3].

Ubuntu:

```
sudo apt update
sudo apt install -y curl python3 ca-certificates
python3 --version
```

#### 2. Установка YCodex

Скрипт из интернета сначала читают. Скачайте и откройте его; листать – пробел, выйти – клавиша q:

Ubuntu:

```
d=$(mktemp -d) && curl -sSfL https://storage.yandexcloud.net/yc-codex/install.sh -o "$d/install.sh" && less "$d/install.sh"
```

Скачалось без ошибок – запустите в том же окне. Спросит про PATH – ответьте Y:

Ubuntu:

```
bash "$d/install.sh"
```

Закройте окно и откройте снова, затем:

Ubuntu:

```
ycodex --version
```

> Должна появиться версия. В ноябре 2026 года установщик выбирает 1.1.1.

В руководстве Яндекса скачивание и запуск объединены в одну строку [1]. Архив программы установщик сверяет по SHA-256 с того же сервера [3].

## 5. Вход и первый запуск

#### 3. Вход

Подставьте свои идентификаторы, кавычки сохраните:

Ubuntu:

```
ycodex --cloud-id "CLOUD_ID" --folder-id "FOLDER_ID" login
```

Откроется браузер с подтверждением доступа к Yandex Cloud [1]. Входите тем пользователем, на которого оформлена подписка. Из WSL браузер может не открыться: скопируйте ссылку из терминала в браузер Windows (Ctrl и щелчок по ссылке) и дождитесь сообщения об успешном входе.

В руководстве флаги короче, `--cloud` и `--folder` [1]; сборка 1.1.1 принимает и те, и другие.

#### 4. Первый запрос

Ubuntu:

```
mkdir -p ~/projects/ycodex-test
cd ~/projects/ycodex-test
ycodex --cloud-id "CLOUD_ID" --folder-id "FOLDER_ID"
```

Первый запрос – без файлов и команд:

Запрос агенту:

```
Ответь одним словом «готово». Не используй инструменты, не читай и не изменяй файлы.
```

> Ответил «готово» – связь с моделью есть.

#### 5. Выбор модели

Внутри YCodex:

```
/model
```

По умолчанию стоит DeepSeek [1]. По подписке доступны DeepSeek v4.1 Flash, Qwen 3.6 35b и Alice AI Flash [4]. Нужна модель Яндекса – выберите Alice AI Flash, если она есть в списке.

#### 6. Чтобы не вводить коды каждый раз

Откройте второе окно Ubuntu (терминала Linux): в первом работает YCodex.

Ubuntu:

```
mkdir -p ~/.yc-codex
nano ~/.yc-codex/config.toml
```

Две строки – **в начале файла**, выше первого раздела в квадратных скобках. Такие ключи уже есть – поправьте значения, вторых не добавляйте:

config.toml:

```
yc_cloud_id = "CLOUD_ID"
yc_folder_id = "FOLDER_ID"
```

Сохранить: Ctrl+O, Enter; выйти: Ctrl+X. Дальше достаточно команды `ycodex`, а `ycodex doctor` проверит установку, вход и доступ к сервису [1]. В руководстве эти ключи названы `cloud` и `folder` [1], но сборка 1.1.1 по своей справке ждёт `yc_cloud_id` и `yc_folder_id`.

#### 7. Ваш проект

Для скорости держите проект внутри Ubuntu, например в `~/projects`. Папка Windows тоже доступна: `C:\` видна как `/mnt/c` [15].

Ubuntu:

```
cd ~/projects/ycodex-test
explorer.exe .
ycodex
```

Вторая строка открывает папку в Проводнике Windows, точка в конце обязательна [15]. В Linux её не нужно.

## 6. Упражнение: десять замеров и один отчёт

Создайте папку и файл (в окне Ubuntu, где YCodex не запущен):

```
mkdir -p "$HOME/projects" && d=$(mktemp -d "$HOME/projects/zamery.XXXXXX") && cd "$d" && cat > zamery.csv <<'CSV'
N;Параметр;Номинал, мм;Нижнее отклонение, мм;Верхнее отклонение, мм;Замер, мм
1;Вал, шейка 1;40,000;-0,025;0,000;39,985
2;Вал, шейка 2;40,000;-0,025;0,000;39,972
3;Втулка А, внутренний диаметр;40,000;0,000;0,039;40,021
4;Втулка Б, внутренний диаметр;40,000;0,000;0,039;40,044
5;Фланец А, толщина;12,000;-0,100;0,100;11,950
6;Фланец Б, толщина;12,000;-0,100;0,100;
7;Палец А, диаметр;20,000;-0,013;0,000;19,987
8;Палец Б, диаметр;20,000;-0,013;0,000;199,91
9;Отверстие под болт 1;10,500;0,000;0,180;10,612
10;Отверстие под болт 2;10,500;0,000;0,180;10,500
CSV
```

Файл создан без ошибок – запустите агента в этом же окне (коды сохранены – просто `ycodex`):

```
ycodex --cloud-id "CLOUD_ID" --folder-id "FOLDER_ID"
```

Задание агенту:

```
Прочитай файл zamery.csv. Столбцы разделены точкой с запятой, дробная часть – через запятую. Для каждой строки прибавь отклонения к номиналу и сравни замер с пределами, границы включены. Решение одно на строку: годен, вне допуска, нет замера или сомнительная запись. Пустой замер – «нет замера». Число, невозможное для такой детали, – «сомнительная запись»: не исправляй и считай отдельно. По обоим случаям задай вопрос контролёру. Считай скриптом, не в уме. Ничего не додумывай, исходный файл не меняй. Результат сохрани в otchet.md: таблица, итоги, вопросы. Сначала покажи план и подожди моего «да».
```

Прочитайте план. Согласны – ответьте «да». Запросит разрешение на команду – прочитайте её до подтверждения. Дождитесь файла otchet.md и отправьте запрос на проверку:

```
Пересчитай итоги отдельной командой и сравни с otchet.md. Если есть расхождение, покажи строку.
```

## 7. Данные

Красное (сведения ограниченного доступа, персональные данные, пароли, чужая тайна) – не вводить. Жёлтое (рабочие документы) – только с разрешения безопасности и в разрешённом контуре. Зелёное (учебное, открытое) – можно; для показа берите только zamery.csv.

«По умолчанию AI Studio может сохранять данные запросов и ответов моделей для улучшения работы сервиса» [8]. В API логирование отключают заголовком x-data-logging-enabled: false [9], для всего облака – через поддержку [8]. Как передать этот заголовок из YCodex, в прочитанных руководствах не сказано.

## 8. Если не получилось

| Что видно | Что делать |
|---|---|
| `ycodex: command not found` | Вы в Ubuntu, а не в PowerShell? Перезапустите терминал. Не помогло – `~/.local/bin/ycodex --version` и строка PATH, которую напечатал установщик [3]. |
| Установщик просит Python или curl | Шаг «Подготовка» – внутри Ubuntu, затем повторить установку. |
| Ошибка доступа к облаку или подписке | Тот ли пользователь вошёл, активна ли подписка, оба ли кода от одного облака, есть ли роли `resource-manager.clouds.member` и `resource-manager.viewer` [5]. Затем `ycodex doctor`; коды ещё не сохранены – с теми же двумя флагами, что при входе. |
| Браузер не открылся | Скопируйте ссылку из терминала в браузер Windows. Не вышло – повторите команду входа целиком, с обоими кодами. |
| Не видит настройки из файла | Ключи `yc_cloud_id` и `yc_folder_id` стоят в начале `~/.yc-codex/config.toml`, не внутри раздела, без повторов. |
| «Лимит исчерпан» | Лимит считается скользящим окном: 5 часов и неделя [4]. Ждать или оплатить сброс [7]. |
| WSL стоит на 0 % | `wsl --install --web-download -d Ubuntu` [13]. |

| Строка | Пределы, мм | Замер | Решение |
|---|---|---|---|
| 1 | 39,975–40,000 | 39,985 | годен |
| 2 | 39,975–40,000 | 39,972 | вне допуска, ниже на 0,003 |
| 3 | 40,000–40,039 | 40,021 | годен |
| 4 | 40,000–40,039 | 40,044 | вне допуска, выше на 0,005 |
| 5 | 11,900–12,100 | 11,950 | годен |
| 6 | 11,900–12,100 | нет | нет замера, вопрос контролёру |
| 7 | 19,987–20,000 | 19,987 | годен, на границе |
| 8 | 19,987–20,000 | 199,91 | сомнительная: вопрос контролёру, до сверки число не исправлять |
| 9 | 10,500–10,680 | 10,612 | годен |
| 10 | 10,500–10,680 | 10,500 | годен, на границе |

Итого: годны шесть (1, 3, 5, 7, 9, 10), вне допуска две (2, 4), без замера одна (6), сомнительная одна (8).
