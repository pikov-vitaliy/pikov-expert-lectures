# Слайды курса «ИИ для инженеров»: сборка

Один исходник – три формата с одинаковой раскладкой: HTML для сайта, PPTX и PDF (экспорт из PowerPoint).

## Состав

- `decks/deck_XX.json` – текст колод (XX: день и тема, `11` … `52`). Текст слайдов меняется только здесь.
- `viz/deck_XX.json` – оформление по номеру исходного слайда: `layout` (cards, rows, list, checklist, chart, compare, flow, grid), `icon`/`icons` (значки Lucide), `tone` (teal – модель, orange – решение инженера, red – риск), `numbered`, `stats` (крупные числа: значение и подпись – точные куски текста слайда), `chart` (столбцы или полосы, числа только из текста слайда; `limit` – пунктирная линия допуска), `side`, `drop`; `_order` – порядок слайдов, `_topic_icon` – значок титульного.
- `engine.py` – раскладка: колода + оформление -> сцена (`*.scene.json`) и HTML.
- `build_pptx.js` – сцена -> PPTX (pptxgenjs).
- `export_pdf.ps1` – PPTX -> PDF через установленный PowerPoint (COM).
- `svg2png.py` – схемы Archify из `08-Схемы/*.svg` -> PNG для слайдов (Chrome).
- `build_all.py` – всё вместе для выбранных колод, плюс PNG страниц и обзорные листы.
- `check.py` – целостность: каждая строка `decks/` есть на своём слайде, нового текста нет, числа на диаграммах взяты из текста слайда.

## Как собрать

```
npm ci
python build_all.py            # все колоды; или: python build_all.py 31 32
python check.py                # ОШИБОК 0
```

Нужны: Python 3.11 с Pillow, Playwright (Chrome) и pymupdf; Node.js; Microsoft PowerPoint (для PDF); шрифты Calibri и Consolas.
Рабочая папка – `_work` рядом со скриптами или переменная `SLIDES_WORK`. Папка курса с днями – `kamaz-ai/_src` или переменная `COURSE_ROOT`.
Готовые HTML, PPTX и PDF копируются в `02-Слайды` соответствующего дня, затем сайт пересобирается штатно.

## Что учтено

- Макеты PPTX названы латиницей: с кириллическим именем макета и фоновой картинкой PowerPoint не открывает файл.
- Диаграммы рисуются фигурами, а не встроенным графиком PowerPoint: подписи чисел с запятой при любых региональных настройках Windows.
- Между числом и единицей ставится неразрывный пробел, «50 %» не рвётся на строки.
- Записи-папки удаляются из архива PPTX: с ними файл плохо открывается через облачные сервисы.
