# Практика к теме 4.1. Расчёт с ИИ и его проверка

**Время:** 3 академических часа (08:45–10:15 и 10:25–11:10).
**Что понадобится:** доступ хотя бы к одному сервису: основные – GigaChat и Алиса AI; DeepSeek – при обосновании и если доступ к нему разрешён; Qwen – для пробы на учебных данных по указанию преподавателя. Кроме того, понадобятся файл «Учебный кейс ЭС-24: дополнение к четвёртому дню» (ТЗ – редакция 1 из кейса первого дня, если в задании не сказано иное), калькулятор, табличный редактор, если он есть на рабочем месте.
**Правило:** в сервисы отправляем только материалы учебного кейса. Рабочие расчёты, чертежи и данные изделий не вставляем.

Если доступа к сервису нет, работайте по экрану преподавателя: он отправляет запросы, вы проверяете ответы. Все проверки в этой практике делаются без сервиса – калькулятором и таблицей.

## Задание 1. Пошаговый расчёт и проверка каждого шага (55 мин)

**По выбору.** Конструкторы могут вместо задачи 1 решить задачу 3 – посадку вала во втулке (вариант К в конце задания). Ход проверки тот же: исходные данные, допущения, каждый шаг.

**1а. Получить расчёт (15 мин).** Откройте новый чат и отправьте запрос. Вместо квадратных скобок вставьте раздел 1 дополнения к кейсу.

```
Я инженер, проверяю сечение провода в цепи фар грузового автомобиля
с бортовой сетью 24 В. Условие задачи ниже.

[вставьте раздел 1 дополнения к кейсу: условие задачи 1]

Реши задачу пошагово. Требования к ответу:
1. Сначала выпиши все исходные данные с единицами и все допущения,
   которые ты принимаешь.
2. Назови расчётную схему: какую длину провода ты берёшь и почему.
3. Каждый шаг оформи строкой таблицы: величина – формула –
   подстановка чисел с единицами – результат с единицей.
4. Сечение выбери из ряда, указанного в условии.
5. Если для расчёта не хватает данных, перечисли их и не подставляй
   значения от себя.
```

Файл дополнения к кейсу целиком не прикладывайте: в нём есть учебный расчёт с ошибками и контрольные значения этой же задачи, и модель их увидит. Если хотите проверить загрузку файла, скопируйте раздел 1 в отдельный файл TXT, приложите его и напишите «условие задачи – в приложенном файле».

**1б. Проверить каждый шаг (40 мин).** Заполните таблицу проверки. Числа пересчитывайте на калькуляторе, не глядя в ответ модели.

| Что проверяем | Как | Ответ модели | Мой пересчёт | Совпало? |
|---|---|---|---|---|
| Исходные данные | Каждое число и единица сверены с условием | | | |
| Расчётная схема | Длина провода l = 2L = 12 м | | | |
| Допущения | Названы ли постоянный ток, 20 °C, двухпроводная схема | | | |
| Размерности | Подставить единицы в каждую формулу | | | |
| Допустимое падение | 3 % от 24 В | | | |
| Минимальное сечение | Пересчёт на калькуляторе | | | |
| Выбор из ряда | Ближайшее не меньше расчётного | | | |
| Падение при выбранном сечении | Абсолютное значение и доля от 24 В в процентах | | | |
| Мощность потерь | I² · R | | | |
| Предохранитель | По учебному правилу из условия | | | |
| Прикидка | Обратное умножение: S_min × 0,72 должно дать 1,26 | | | |

**Контрольный пример.** Прежде чем пересчитывать задачу, проверьте свою формулу на примере с известным ответом: ток 10 А, длина цепи 10 м, сечение 1 мм², ρ = 0,0175 Ом·мм²/м. Должно получиться R = 0,175 Ом и ΔU = 1,75 В.

**Результат:** заполненная таблица проверки и вывод в одну-две строки: можно ли взять ответ модели в работу и что пришлось исправить.

### Вариант К. Посадка вала во втулке (для конструкторов)

Вместо задачи 1 можно решить задачу 3 – раздел 8 дополнения к кейсу. Время то же: 15 мин на расчёт, 40 мин на проверку.

```
Я инженер-конструктор, проверяю посадку оси во втулке: Ø20 H7/f7.
Исходные данные – учебный фрагмент таблиц допусков ниже.
1. Выпиши предельные отклонения отверстия H7 и вала f7 в микрометрах.
2. Посчитай предельные размеры отверстия и вала в миллиметрах,
   наибольший и наименьший зазоры, допуск посадки.
3. Определи характер посадки.
4. Предложи шероховатость поверхностей отверстия и вала.
Опирайся только на данные ниже. Перечисли допущения. В конце
отдельно: что взято из данных, а что из твоих общих знаний
и требует проверки по стандарту.

[вставьте раздел 8 дополнения к кейсу]
```

Проверьте:

- отклонения: отверстие H7 – от 0 до +IT7, вал f7 – от основного отклонения вниз на IT7; сверьте с учебной таблицей, а не с памятью модели;
- миллиметры и микрометры: 21 мкм – это 0,021 мм, а не 0,21;
- зазоры: наибольший – наибольшее отверстие минус наименьший вал, наименьший – наоборот; допуск посадки равен сумме допусков отверстия и вала;
- шероховатость: в данных её нет. Если модель назвала значения, это предложение по общим знаниям, а не результат расчёта: отметьте его «не проверено» и назовите, по какому документу проверили бы.

## Задание 2. Найти ошибки в готовом расчёте (35 мин)

В разделе 2 дополнения к кейсу есть расчёт, «выполненный моделью». В нём несколько ошибок разного рода. Найдите как можно больше, проверяя каждый шаг. Для каждой ошибки запишите:

| Шаг | Фрагмент | Что не так | Вид ошибки | Какой проверкой поймали |
|---|---|---|---|---|
| | | | | |

Подсказка по видам ошибок: арифметика, логика выбора, единицы измерения, подстановка не того значения. Подсказка по проверкам: пересчёт, прикидка с обратным умножением, анализ размерностей, сверка с условием.

Отдельно ответьте на вопрос: почему итоговый ответ выглядит убедительно, хотя он неверен?

## Задание 3. Формула для электронной таблицы (30 мин)

**По выбору.** Руководители и те, кто планирует работы, могут вместо формул для провода сделать план-график по рабочим дням (вариант Р в конце задания).

**3а. Получить формулу (10 мин).** Отправьте модели запрос. Укажите свой табличный редактор и язык его интерфейса.

```
Мне нужны формулы для табличного редактора [Excel / Р7-Офис /
LibreOffice], интерфейс [русский / английский]. Данные расположены так:
строка 1 – заголовки, расчёт со строки 2.
A – ток I, А; B – длина цепи l (прямой и обратный провод), м;
C – сечение S, мм²; D – удельное сопротивление, Ом·мм²/м.
Нужны формулы для столбцов:
E – сопротивление проводов, Ом;
F – падение напряжения, В;
G – падение в процентах от 24 В;
H – текст «годится», если G не больше 3, иначе «не годится»;
I – минимальное сечение при допустимом падении 3 % от 24 В.
Дай формулу для каждой ячейки строки 2 и поясни, что она считает.
```

**3б. Проверить на контрольных значениях (20 мин).** Если табличный редактор есть, введите формулы и три контрольные строки из раздела 3 дополнения к кейсу. Сравните результат с таблицей контрольных значений. Если редактора нет, подставьте числа строки 2 в формулы вручную.

Проверьте ещё три вещи:

- удвойте длину в строке 2: падение напряжения должно удвоиться;
- скопируйте формулы на строку 3: ссылки должны указывать на строку 3;
- оставьте сечение пустым: что покажет формула и что с этим делать.

**Результат:** формулы, проверенные на контрольных значениях, или список найденных в них ошибок.

### Вариант Р. План-график по рабочим дням (для руководителей)

Вместо формул для провода можно сделать план-график – раздел 9 дополнения к кейсу. Время то же: 10 мин на формулы, 20 мин на проверку.

```
Мне нужны формулы для табличного редактора [Excel / Р7-Офис /
LibreOffice], интерфейс [русский / английский]. План-график из
четырёх работ, каждая начинается в следующий рабочий день после
окончания предыдущей. Столбцы: A – работа, B – длительность,
C – единица (рабочие или календарные дни), D – начало, E – окончание.
Список нерабочих праздничных дней – в диапазоне H2:H10.
Дай формулы для D и E так, чтобы они учитывали выходные, праздники
и календарные дни для работы 2. Поясни каждую формулу.
Перечисли допущения: с какого дня считается первый день работы.

[вставьте раздел 9 дополнения к кейсу]
```

Проверьте:

- даты вводите функцией ДАТА или как даты, а не текстом;
- первый день работы считается рабочим: окончание работы из N рабочих дней – это РАБДЕНЬ(начало; N−1; праздники), а не РАБДЕНЬ(начало; N; праздники);
- работа 2 считается в календарных днях: 14 дней с 02.12 – это по 15.12, а не по 18.12;
- уберите диапазон праздников из формулы: какую дату окончания работы 4 вы получите? Почему она неверна?
- сверьте окончание каждой работы с календарём хотя бы на двух датах вручную.

## Дополнительно, для тех, кто уже работает с ИИ
