## С чего начать

1. **Откройте `index.html`** — двойным кликом, в любом браузере. Это лекция целиком, 16 разделов. Работает без интернета, ссылки внутри неё ведут на файлы этого же архива. Слева — оглавление, разделы подписаны по парам занятия.
2. **Прочитайте `materials/konspekt.md`** — то же самое, но текстом и короче. Удобно для повторения.
3. **Работайте по `materials/praktikum.md`** — четыре практических задания плюс одно со звёздочкой.
4. **Код лежит в `code/`** — там же `spravka.md` с таблицей «какой файл к какой паре».

## Что нужно установить

**Ничего.** Достаточно Python 3.11 или новее. Всё учебное приложение написано на стандартной библиотеке: и база данных `sqlite3`, и тесты `unittest` идут в комплекте с самим Python.

Проверить, что Python есть:

```
py --version
```

**Все команды ниже выполняются из каталога `code`** — сначала перейдите в него. Распакуйте архив в свою папку (например, в «Документы»), затем:

```
cd code
```

Запустить первую программу:

```
py step1_list.py
```

Запустить тесты:

```
py -m unittest -v test_journal.py
```

Проверить, что вы в нужном каталоге, можно так: команда `dir step1_list.py` должна найти файл.

> [!warning] Не распаковывайте архив внутрь чужого git-репозитория
> В задании 1 вы будете создавать свой репозиторий командой `git init`. Если распаковать архив внутрь уже существующего репозитория, команды `git add`, `commit` и `tag` уйдут в него, а не в ваш учебный проект. Распакуйте в отдельную папку — например, `Документы\27-07-2026`.

Инструменты из `requirements-dev.txt` (линтер, анализатор безопасности) — только для пятой пары и только по желанию. Без них всё остальное работает.

## Если при запуске появилась ошибка UnicodeEncodeError

Это не ошибка вашего кода. Так проявляется кодировка консоли Windows: она по умолчанию не UTF-8, а кириллица в выводе требует именно его. Во всех файлах архива защита от этого уже стоит — строка:

```python
sys.stdout.reconfigure(encoding="utf-8")
```

Если пишете свой файл с выводом по-русски — добавьте её же в начало блока `if __name__ == "__main__":`.
