## Что нужно установить

**Ничего.** Достаточно Python 3.11 или новее. Всё учебное приложение написано на стандартной библиотеке: и база данных `sqlite3`, и тесты `unittest` идут в комплекте с самим Python.

Проверить, что Python есть:

```
py --version
```

Запустить первую программу:

```
py step1_list.py
```

Запустить тесты:

```
py -m unittest -v test_journal.py
```

Инструменты из `requirements-dev.txt` (линтер, анализатор безопасности) — только для пятой пары и только по желанию. Без них всё остальное работает.

## Если при запуске появилась ошибка UnicodeEncodeError

Это не ошибка вашего кода. Так проявляется кодировка консоли Windows: она по умолчанию не UTF-8, а кириллица в выводе требует именно его. Во всех файлах архива защита от этого уже стоит — строка:

```python
sys.stdout.reconfigure(encoding="utf-8")
```

Если пишете свой файл с выводом по-русски — добавьте её же в начало блока `if __name__ == "__main__":`.
