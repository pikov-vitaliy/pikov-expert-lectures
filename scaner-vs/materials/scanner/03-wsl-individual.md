# Вариант 2. Индивидуальный стенд Сканер-ВС 7 в WSL 2

## Когда выбирать

Вариант предназначен для самостоятельной работы на Windows 10/11 с WSL 2, когда отдельный гипервизорный стенд не нужен.

## Обязательное получение продукта

1. Заполните [форму демоверсии производителя](https://scaner-vs.ru/#form).
2. Получите по почте ссылку на актуальную демоверсию Сканер-ВС 7 Base и файл лицензии.
3. Не передавайте файлы другим слушателям.

## Ограничения модели

- WSL 2 использует виртуальную сеть; IP дистрибутива может измениться после перезапуска.
- Стабильный доступ с других машин требует отдельно проверенного перенаправления портов.
- Для индивидуальной практики предпочтителен доступ только через `https://localhost`.
- Не обещайте сканирование самого Windows-хоста из WSL без отдельной проверки маршрутизации и правил брандмауэра.

## Подготовка

1. Проверьте поддержку виртуализации и WSL 2.
2. Установите компоненты WSL штатными средствами Windows.
3. Зафиксируйте версию Windows, WSL и дистрибутива Linux.
4. Установите Сканер-ВС по текущей официальной инструкции.
5. Активируйте полученный файл лицензии.
6. Немедленно смените стандартные учетные данные продукта.

## Безопасная сеть

1. Не публикуйте HTTP-порт 80.
2. Если нужен доступ извне хоста, разрешите 443 только конкретному адресу или лабораторной подсети.
3. Запишите созданные правила `portproxy` и брандмауэра.
4. После перезапуска WSL проверьте его новый IP и работоспособность правила.
5. Удаляйте конкретное правило, созданное для занятия; не используйте общий `portproxy reset`.

## Практическая последовательность

Выполните [общий сценарий четырех блоков](01-common-workflow.md), используя только разрешенные цели. Если отдельные ВМ-цели отсутствуют, ограничьтесь исследованием специально созданной Host-only сети или демонстрацией преподавателя.

## Результат

- версия и конфигурация WSL;
- адрес интерфейса и схема доступа;
- перечень правил брандмауэра/portproxy;
- подтверждение смены стандартного пароля без раскрытия нового;
- заполненный [шаблон отчета](REPORT-TEMPLATE.md).
