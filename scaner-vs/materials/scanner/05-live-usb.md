# Вариант 4. Практика Сканер-ВС 7 в режиме Live USB

## Статус варианта

Технология Live USB документирована для Сканер-ВС 7.x. Перед занятием преподаватель отдельно подтверждает у производителя наличие актуального Live-образа и подходящей лицензии. Обычный дистрибутив из формы демоверсии не следует автоматически считать Live-образом.

## Требования

- отдельный USB-носитель объемом не менее 32 ГБ;
- отдельный учебный компьютер с разрешенной загрузкой с USB;
- образ только из прямого доверенного источника производителя и ожидаемый SHA-256 из подписанного преподавателем реестра либо проверяемая подпись производителя;
- резервная копия данных: запись образа уничтожит прежнее содержимое носителя.

## Подготовка

1. Получите продукт через [официальную форму](https://scaner-vs.ru/#form) и уточните у производителя доступность Live-образа.
2. Получите ожидаемый SHA-256 непосредственно от производителя либо из подписанного преподавателем реестра по аутентифицированному независимому каналу. Хеш рядом с образом в том же непроверенном сообщении не считается независимым подтверждением.
3. До открытия Rufus преподаватель обязательно сверяет образ; значение-заполнитель вызывает STOP:

   ```powershell
   $ImagePath = 'C:\Lab\scanner-live.iso'
   $ExpectedImageSha256 = '<64_HEX_ИЗ_АУТЕНТИФИЦИРОВАННОГО_РЕЕСТРА>'
   if ($ExpectedImageSha256 -notmatch '^[0-9A-Fa-f]{64}$') {
     throw 'STOP: отсутствует корректный ожидаемый SHA-256; образ не записывать.'
   }
   $ActualImageSha256 = (Get-FileHash -LiteralPath $ImagePath -Algorithm SHA256 -ErrorAction Stop).Hash
   if ($ActualImageSha256 -ne $ExpectedImageSha256) {
     throw 'STOP: SHA-256 Live-образа не совпал; Rufus не открывать и USB не изменять.'
   }
   ```

4. Запись образа выполняет **только преподаватель** на выделенной станции и только после успешной проверки SHA-256 или подписи. Слушателям raw-disk команды не выдаются.
5. До открытия Rufus преподаватель выполняет read-only инвентаризацию и записывает номер, модель, `SerialNumber`, `UniqueId`, размер, `IsBoot` и `IsSystem`:

   ```powershell
   Get-Disk | Select-Object Number, FriendlyName, SerialNumber, UniqueId, Size, IsBoot, IsSystem
   ```

6. Носитель допускается к записи только при одновременном выполнении условий: серийный номер и размер совпадают с паспортом учебного USB; `IsBoot=False`; `IsSystem=False`; второй преподаватель визуально подтвердил выбранный диск. При пустом/неоднозначном `SerialNumber`, лишнем внешнем диске или любом расхождении — STOP.
7. Отключите остальные съёмные накопители и используйте Rufus в режиме DD по официальной инструкции. Командная запись по имени `/dev/sdX` в раздаточном материале не применяется.
8. После записи повторно сверьте идентичность USB и только затем загрузите отдельный учебный компьютер; не подключайте его к корпоративной сети.

## Persistence

| Режим | Что происходит | Учебное следствие |
|---|---|---|
| Без Persistence | Настройки, учетные записи и результаты исчезают после перезагрузки | Экспортируйте обезличенный отчет до завершения |
| С Persistence | Проекты, результаты и активация могут сохраняться | Носитель становится чувствительным и требует физической защиты |

## Задание

1. Зафиксируйте режим загрузки и наличие Persistence.
2. Смените стандартные учетные данные.
3. Подключитесь только к изолированной лабораторной сети.
4. Выполните минимальную цепочку: исследование сети → подключение актива → инвентаризация → поиск уязвимостей.
5. Сохраните обезличенный отчет разрешенным способом.
6. Перезагрузите стенд и проверьте ожидаемое сохранение/удаление данных.

## Завершение

- при Persistence преподаватель экспортирует разрешённый обезличенный отчёт, затем очищает только USB, повторно сверив `SerialNumber`, `UniqueId`, `Size`, `IsBoot=False` и `IsSystem=False`;
- без Persistence убедитесь, что данные действительно не сохранились;
- верните настройки загрузки учебного компьютера;
- не оставляйте USB без контроля; слушатели не форматируют и не очищают носитель самостоятельно.
