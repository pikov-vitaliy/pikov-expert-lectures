# Материалы к практическим работам: Сканер-ВС 7 и «Инспектор»

Этот каталог содержит авторские учебные материалы в формате Markdown и ZIP-архивы. В каждом архиве вместе с `.md`-файлами находится автономный офлайн-лендинг (`index.html`) с локальными стилями, сценарием интерфейса и иллюстрацией.

Дистрибутивы, загрузочные образы, виртуальные машины, файлы лицензий, реальные учетные данные и копии руководств производителя в комплект не входят.

Чтобы работать без Интернета, сначала полностью распакуйте выбранный ZIP в отдельную папку, а затем откройте находящийся в корне файл `index.html`. Не запускайте страницу непосредственно из окна архиватора: браузер не сможет надежно загрузить соседние материалы и ресурсы.

## Обязательный шаг до практики со Сканер-ВС

1. Откройте [форму демоверсии на официальном сайте Сканер-ВС](https://scaner-vs.ru/#form).
2. Заполните форму собственными актуальными данными и примите условия, с которыми согласны.
3. Дождитесь письма производителя со ссылкой на демоверсию Сканер-ВС 7 Base и файлом лицензии.
4. Скачайте актуальный на момент запроса дистрибутив самостоятельно.
5. Не пересылайте дистрибутив или лицензию другим слушателям и не включайте их в общий архив занятия.

Условия демоверсии, перечень поддерживаемых ОС, количество IP и срок лицензии могут меняться. Проверяйте их непосредственно на странице производителя перед занятием.

## Как использована инструкция по установке Сканер-ВС 7

Команды WSL, `portproxy`, Windows Firewall и installer перенесены из предоставленного файла `Установка Сканер-ВС 7 для УЦ Маском.pdf`, страницы 3-5, в [подробную Markdown-инструкцию](scanner/03-wsl-individual.md). Сам PDF в публичные материалы и ZIP не включен.

При переносе исправлено только представление команд: визуальные переносы собраны в копируемые однострочные команды, приглашение `PS C:\>` исключено, а сокращенная строка `sudo bash scanner...` явно помечена как неисполняемая. Имена свежего `.run`-файла и лицензии проверяются по фактически полученной поставке. Дополнительные команды проверки и первый вход сверены с текущей официальной документацией Сканер-ВС 7.x.

## Как использована методичка Сканер-ВС 6

Локальная официальная методичка по Сканер-ВС 6 использована как исторический источник последовательности упражнений:

1. исследование сети;
2. сравнение проверки без учетных данных и с аутентифицированным подключением;
3. инвентаризация перед поиском уязвимостей;
4. ручная проверка возможных ложных срабатываний;
5. контролируемая проверка паролей;
6. формирование отчета.

В публичные материалы не перенесены интерфейс версии 6, старые IP-адреса, логины, пароли, ссылки на готовые образы, мостовая схема сети, скриншоты и интеграция со сторонним SIEM. Названия задач и порядок действий сверены с документацией Сканер-ВС 7.x.

## Общие правила безопасности

- Работайте только с собственными или письменно разрешенными учебными системами.
- Для уязвимых машин используйте только Host-only/Internal Network; сетевой мост запрещен.
- Не используйте реальные персональные данные, рабочие документы, ключи и пароли.
- Перед изменениями создайте снимок ВМ; после занятия отзовите временные реквизиты и удалите чувствительные отчеты.
- Отчет средства не доказывает отсутствие иных проблем и не является аттестационным заключением.
