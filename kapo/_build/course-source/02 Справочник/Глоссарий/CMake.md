# CMake

## Термин
- English: CMake
- Русский вариант: система описания и генерации сборки C/C++

## Определение
CMake — система управления сборкой, которая описывает цели, зависимости, параметры компиляции и линковки, а затем генерирует файлы для конкретного build tool. Для SCA C/C++ CMake важен как источник фактических зависимостей и флагов сборки.

## Источник
- [CMake buildsystem manual](https://cmake.org/cmake/help/latest/manual/cmake-buildsystem.7.html)

## Как проверять понимание
Слушатель должен уметь объяснить термин на примере реального компонента или артефакта: где он появляется в SBOM/ППК или SCA/OSA-процессе, какой риск возникает при ошибке, какие данные подтверждают вывод и какой контроль нужен в CI/CD, регламенте или отчете.
