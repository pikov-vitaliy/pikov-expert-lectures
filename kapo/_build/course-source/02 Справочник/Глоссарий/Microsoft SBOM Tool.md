# Microsoft SBOM Tool

## Термин
- English: Microsoft SBOM Tool
- Русский вариант: инструмент Microsoft для генерации SBOM

## Определение
Microsoft SBOM Tool — инструмент Microsoft для создания SPDX-совместимых SBOM для различных артефактов с использованием Component Detection и ClearlyDefined. В курсе он применим как пример enterprise-ready build-time SBOM generator.

## Источник
- [Microsoft SBOM Tool](https://github.com/microsoft/sbom-tool)

## Как проверять понимание
Слушатель должен уметь объяснить термин на примере реального компонента или артефакта: где он появляется в SBOM/ППК или SCA/OSA-процессе, какой риск возникает при ошибке, какие данные подтверждают вывод и какой контроль нужен в CI/CD, регламенте или отчете.
