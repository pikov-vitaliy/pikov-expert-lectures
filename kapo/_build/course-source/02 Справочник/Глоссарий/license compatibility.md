# license compatibility

## Термин
- English: license compatibility
- Русский вариант: совместимость лицензий

## Определение
License compatibility — возможность совместно использовать и распространять компоненты с разными лицензиями без нарушения их условий. В SCA это проверяется по конкретному сценарию: статическая/динамическая линковка, modification, distribution, SaaS и source offer.

## Источник
- [Open Source Initiative, Approved Licenses](https://opensource.org/licenses)

## Как проверять понимание
Слушатель должен уметь объяснить термин на примере реального компонента или артефакта: где он появляется в SBOM/ППК или SCA/OSA-процессе, какой риск возникает при ошибке, какие данные подтверждают вывод и какой контроль нужен в CI/CD, регламенте или отчете.
