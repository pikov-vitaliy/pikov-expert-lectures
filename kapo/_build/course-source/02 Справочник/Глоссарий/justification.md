# justification

## Термин
- English: justification
- Русский вариант: обоснование

## Определение
Justification — объяснение, почему для уязвимости, исключения или VEX-статуса принято конкретное решение. В VEX это поле особенно важно для `not_affected`, потому что без причины статус нельзя надежно использовать для снижения приоритета.

## Источник
- [CycloneDX, Security Use Case: Vulnerability Exploitability](https://cyclonedx.org/use-cases/vulnerability-exploitability/)

## Как проверять понимание
Слушатель должен уметь объяснить термин на примере реального компонента или артефакта: где он появляется в SBOM/ППК или SCA/OSA-процессе, какой риск возникает при ошибке, какие данные подтверждают вывод и какой контроль нужен в CI/CD, регламенте или отчете.
