# OSA

## Термин
- English: Open Source Analysis (OSA)
- Русский вариант: анализ и защита open source цепочки поставки

## Определение
OSA — контур защиты цепочки поставки open source, в котором сторонние компоненты проверяются на соответствие политикам до загрузки или использования. В CodeScoring OSA включает repository manager plugins и proxy service для автоматического scanning/blocking.

## Источник
- [CodeScoring Documentation, CodeScoring.OSA](https://docs.codescoring.ru/osa/index.en/)

## Как проверять понимание
Слушатель должен уметь объяснить термин на примере реального компонента или артефакта: где он появляется в SBOM/ППК или SCA/OSA-процессе, какой риск возникает при ошибке, какие данные подтверждают вывод и какой контроль нужен в CI/CD, регламенте или отчете.
