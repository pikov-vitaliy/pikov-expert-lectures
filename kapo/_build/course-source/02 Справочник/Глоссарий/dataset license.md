# dataset license

## Термин
- English: dataset license
- Русский вариант: лицензия набора данных

## Определение
Dataset license — условия использования, распространения и производных работ для набора данных. Для AI SBOM важно фиксировать лицензию датасета отдельно от лицензии модели и кода, потому что ограничения attribution, non-commercial, share-alike и privacy могут различаться.

## Источник
- [Creative Commons, Using CC-Licensed Works for AI Training](https://creativecommons.org/using-cc-licensed-works-for-ai-training-2/)

## Как проверять понимание
Слушатель должен уметь объяснить термин на примере реального компонента или артефакта: где он появляется в SBOM/ППК или SCA/OSA-процессе, какой риск возникает при ошибке, какие данные подтверждают вывод и какой контроль нужен в CI/CD, регламенте или отчете.
