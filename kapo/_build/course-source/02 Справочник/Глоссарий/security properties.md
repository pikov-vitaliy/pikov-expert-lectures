# security properties

## Термин
- English: security properties
- Русский вариант: свойства безопасности

## Определение
Security properties — проверяемые характеристики, которые продукт должен сохранять: целостность, подлинность, конфиденциальность, доступность, трассируемость, обновляемость и управляемость уязвимостей. В SBOM/ППК часть свойств подтверждается metadata, hashes, signatures, provenance и VEX.

## Источник
- [NIST CSRC Glossary, security control](https://csrc.nist.gov/glossary/term/security_control)

## Как проверять понимание
Слушатель должен уметь объяснить термин на примере реального компонента или артефакта: где он появляется в SBOM/ППК или SCA/OSA-процессе, какой риск возникает при ошибке, какие данные подтверждают вывод и какой контроль нужен в CI/CD, регламенте или отчете.
