# SPDX License List

## Термин
- English: SPDX License List
- Русский вариант: список лицензий SPDX

## Определение
SPDX License List — курируемый список распространенных лицензий и исключений с короткими идентификаторами, полными именами, текстами и постоянными URL. В SCA он используется для нормализации license detection и policy checks.

## Источник
- [SPDX License List](https://spdx.org/licenses/)

## Как проверять понимание
Слушатель должен уметь объяснить термин на примере реального компонента или артефакта: где он появляется в SBOM/ППК или SCA/OSA-процессе, какой риск возникает при ошибке, какие данные подтверждают вывод и какой контроль нужен в CI/CD, регламенте или отчете.
