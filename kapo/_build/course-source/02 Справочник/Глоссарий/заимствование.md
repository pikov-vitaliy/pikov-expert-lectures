# заимствование

## Термин
- English: third-party code borrowing
- Русский вариант: заимствование стороннего кода

## Определение
Заимствование — включение во внутренний продукт внешнего кода, библиотеки, фрагмента, модели или данных. Для SSDLC это должно фиксироваться как dependency или vendored code с источником, лицензией, версией, evidence и владельцем.

## Источник
- [OpenChain ISO/IEC 5230, License Compliance](https://openchainproject.org/license-compliance)

## Как проверять понимание
Слушатель должен уметь объяснить термин на примере реального компонента или артефакта: где он появляется в SBOM/ППК или SCA/OSA-процессе, какой риск возникает при ошибке, какие данные подтверждают вывод и какой контроль нужен в CI/CD, регламенте или отчете.
