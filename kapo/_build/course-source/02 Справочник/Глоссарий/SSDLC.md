# SSDLC

## Термин
- English: Secure Software Development Life Cycle (SSDLC)
- Русский вариант: жизненный цикл безопасной разработки ПО

## Определение
SSDLC — жизненный цикл разработки, в котором security activities встроены в требования, архитектуру, кодирование, сборку, тестирование, поставку и сопровождение. SCA/OSA — обязательная часть SSDLC для управления сторонними компонентами и supply chain risk.

## Источник
- [NIST SP 800-218, Secure Software Development Framework (SSDF) 1.1](https://csrc.nist.gov/pubs/sp/800/218/final)

## Как проверять понимание
Слушатель должен уметь объяснить термин на примере реального компонента или артефакта: где он появляется в SBOM/ППК или SCA/OSA-процессе, какой риск возникает при ошибке, какие данные подтверждают вывод и какой контроль нужен в CI/CD, регламенте или отчете.
