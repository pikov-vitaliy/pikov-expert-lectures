# ISO 27034

## Термин
- English: ISO/IEC 27034
- Русский вариант: ISO/IEC 27034

## Определение
ISO/IEC 27034 — серия стандартов по безопасности приложений, помогающая организациям встраивать безопасность в процессы управления приложениями. Для курса она поддерживает связку secure SDLC, application security controls и проверяемых требований к компонентам.

## Источник
- [ISO/IEC 27034-1:2011](https://www.iso.org/standard/44378.html)

## Как проверять понимание
Слушатель должен уметь объяснить термин на примере реального компонента или артефакта: где он появляется в SBOM/ППК или SCA/OSA-процессе, какой риск возникает при ошибке, какие данные подтверждают вывод и какой контроль нужен в CI/CD, регламенте или отчете.
