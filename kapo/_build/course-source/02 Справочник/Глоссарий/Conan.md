# Conan

## Термин
- English: Conan
- Русский вариант: пакетный менеджер Conan для C/C++

## Определение
Conan — открытый децентрализованный пакетный менеджер для C/C++, работающий на разных платформах и с разными системами сборки. В SCA он важен как источник lockfile, бинарных пакетов, профилей сборки и координат зависимостей.

## Источник
- [Conan 2 documentation, Introduction](https://docs.conan.io/2/introduction.html)
