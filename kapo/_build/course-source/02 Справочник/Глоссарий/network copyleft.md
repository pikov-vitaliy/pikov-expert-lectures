# network copyleft

## Термин
- English: network copyleft
- Русский вариант: сетевой копилефт

## Определение
Network copyleft — copyleft-обязательство, срабатывающее при предоставлении программы пользователям через сеть, а не только при передаче копии. Классический пример — AGPL, требующая предоставлять исходный код модифицированной серверной программы пользователям, взаимодействующим с ней по сети.

## Источник

## Как проверять понимание
Слушатель должен уметь объяснить термин на примере реального компонента или артефакта: где он появляется в SBOM/ППК или SCA/OSA-процессе, какой риск возникает при ошибке, какие данные подтверждают вывод и какой контроль нужен в CI/CD, регламенте или отчете.
