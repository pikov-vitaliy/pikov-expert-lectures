# SPDX

## Термин
- English: Software Package Data Exchange (SPDX)
- Русский вариант: стандарт обмена данными о пакетах ПО SPDX

## Определение
SPDX — открытый стандарт для обмена сведениями о software bill of materials, компонентах, лицензиях, copyright и связанных security references. В курсе он рассматривается как один из базовых форматов SBOM/ППК наряду с CycloneDX.

## Источник
- [SPDX, Overview](https://spdx.dev/learn/overview/)

## Как проверять понимание
Слушатель должен уметь объяснить термин на примере реального компонента или артефакта: где он появляется в SBOM/ППК или SCA/OSA-процессе, какой риск возникает при ошибке, какие данные подтверждают вывод и какой контроль нужен в CI/CD, регламенте или отчете.
