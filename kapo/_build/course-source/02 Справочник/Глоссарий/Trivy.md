# Trivy

## Термин
- English: Trivy
- Русский вариант: сканер безопасности Trivy

## Определение
Trivy — универсальный security scanner от Aqua Security для поиска CVE, misconfigurations, secrets, license issues и SBOM-related данных в репозиториях, файловых системах, контейнерах и Kubernetes. В SCA важно фиксировать targets, scanners и источник баз данных.

## Источник
- [Trivy, The All-in-One Security Scanner](https://trivy.dev/)

## Как проверять понимание
Слушатель должен уметь объяснить термин на примере реального компонента или артефакта: где он появляется в SBOM/ППК или SCA/OSA-процессе, какой риск возникает при ошибке, какие данные подтверждают вывод и какой контроль нужен в CI/CD, регламенте или отчете.
