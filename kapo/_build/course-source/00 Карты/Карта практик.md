# 🧪 Карта практик

> [!info] Живая карта
> Список строится `dataview` из frontmatter практик. Добавите новую практику с полем `type: practice` — она появится здесь автоматически. Нужен включённый плагин **Dataview** и режим чтения.

## Все практики по модулям

```dataview
TABLE WITHOUT ID
  link(file.link, practice) as "№",
  file.name as "Практика",
  join(tools, ", ") as "Инструменты",
  gate as "Gate",
  difficulty as "Сложность"
FROM "03 Практикум"
WHERE type = "practice"
SORT practice ASC
GROUP BY ("Модуль " + module)
```

## Только C/C++ (ядро курса)

```dataview
LIST join(tools, ", ")
FROM "03 Практикум"
WHERE type = "practice" AND contains(ecosystem, "cpp")
SORT practice ASC
```

## Практики с CI-гейтом

```dataview
LIST
FROM "03 Практикум"
WHERE type = "practice" AND gate = "ci"
SORT practice ASC
```
