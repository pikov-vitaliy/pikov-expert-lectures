# Нормативка

Карта раздела нормативных и методических источников для SCA/OSA, SBOM/ППК, лицензионной чистоты и безопасности цепочки поставки.

- [[05 Нормативка/OpenChain ISO IEC 5230|OpenChain ISO/IEC 5230]]

## Как пользоваться

Для занятия берите не сам список стандартов, а связку «требование → артефакт → evidence → gate». В практиках эта связка обычно выглядит так: SBOM/ППК, VDR/VEX, реестр лицензий, журнал исключений, протокол приёмки поставки и настройка CI/CD gate. Для VEX используйте отдельную справку: [[02 Справочник/VEX в процессе РБПО - откуда берется и как выпускать|VEX в процессе РБПО]].
