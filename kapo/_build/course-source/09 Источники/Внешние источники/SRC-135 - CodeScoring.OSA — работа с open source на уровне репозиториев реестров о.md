# CodeScoring.OSA — работа с open source на уровне репозиториев реестров о

## URL
https://docs.codescoring.ru/user-guide/osa/

## Раздел исходного обзора
15. CodeScoring — детальный разбор

## Контекст из обзора
- **CodeScoring.OSA** — работа с open source на уровне репозиториев/реестров образов, политики OSA, обновление данных о компонентах. Плагины для **Nexus**, **JFrog**, **Сфера**. Сервис **OSA Proxy** (и OSA Proxy Go) — перенос композиционного анализа на самый ранний этап (момент установки пакетов) с блокировкой небезопасных пакетов при загрузке из внешних индексов; поддержка Maven, NPM, NuGet, PyPI, Go, Composer, RubyGems, Debian, Docker, Alpine (APK), RPM — https://docs.codescoring.ru/user-guide/osa/

## Что взято в курс
Использовать для подготовки пилота и вопросов поставщику: C/C++ build scan, OSA Proxy, offline/on-premise, права агента, ограничения бинарного анализа.

## Где применять
- лекции по соответствующему разделу;
- справочные карточки инструментов и стандартов;
- практические работы и вопросы для самопроверки.
