## Контекст из обзора
- **CodeScoring.SCA** — анализ манифестов, разрешение транзитивных зависимостей, идентификация open source включений в коде; строит реестр компонентных связей (SBOM), обогащённый данными об уязвимостях и лицензиях. Документация: запуск сканирования, обзор зависимостей, работа с уязвимостями, история, выгрузка результатов — https://docs.codescoring.ru/user-guide/sca/

Использовать для подготовки пилота и вопросов поставщику: C/C++ build scan, OSA Proxy, offline/on-premise, права агента, ограничения бинарного анализа.
