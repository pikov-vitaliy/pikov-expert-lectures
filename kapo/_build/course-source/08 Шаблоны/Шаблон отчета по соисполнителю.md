# Шаблон отчета по соисполнителю

## Назначение
Агрегированный отчёт по одному соисполнителю за поставку или период: сводные метрики качества данных по всей поставке, число unresolved, соблюдение SLA доработки, динамика. В отличие от отчёта по компоненту (одна библиотека вглубь), здесь оценивается поставка целиком и сам поставщик.

## Когда применяется
Формируется по завершении приёмки поставки и периодически (например, по релизам) для оценки соисполнителя. Используется при пересмотре договорных условий и при эскалации.

> [!info] Агрегат, а не глубина
> Этот отчёт суммирует поставку. Детальные решения по отдельным компонентам — в [[Шаблон отчета по компоненту]], нераспознанное — в [[Реестр unresolved libraries]].
