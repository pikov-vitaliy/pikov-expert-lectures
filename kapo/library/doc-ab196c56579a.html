NIST SSDF

Термин

  • English: NIST Secure Software Development Framework (SSDF)
  • Русский вариант: NIST SSDF

Определение

NIST SSDF — набор практик безопасной разработки ПО, которые можно встроить в разные SDLC-модели. Для SCA/OSA особенно важны практики подготовки организации, защиты ПО, производства хорошо защищенного ПО и реагирования на уязвимости.

Источник

  • NIST SP 800-218, Secure Software Development Framework (SSDF) 1.1

Как проверять понимание

Слушатель должен уметь объяснить термин на примере реального компонента или артефакта: где он появляется в SBOM/ППК или SCA/OSA-процессе, какой риск возникает при ошибке, какие данные подтверждают вывод и какой контроль нужен в CI/CD, регламенте или отчете.
